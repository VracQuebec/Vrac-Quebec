# Vrac Quebec Simple

Je veux un nouveau site qui va s'appeler Vrac Quebec. Le site internet doit etre super simple pour des gens qui recherche du matériel comme de la terre, sable, gravier, roche concasser. Le client doit arriver sur une interface simple ou il repond directement a des questions pour cibler sa demande .  Nous pouvons prendre le questionnaire que l'autre site interner que nous avons créer
