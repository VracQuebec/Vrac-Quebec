## Ajustement de rendu limité à la phase 5F

Pour les brouillons marqués `phase5f-p2`, le gabarit masque le bandeau de livraison et le compteur automatique de points de dépôt, puis emploie une invitation neutre à présenter le besoin. Cet ajustement empêche les promesses opérationnelles non validées; les pages existantes conservent leur rendu.
